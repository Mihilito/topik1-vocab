# TOPIK Ⅰ 単語トレーニング

韓国語能力試験 TOPIK Ⅰ（初級 1〜2級）の頻出単語 370 語を 4 択で出題する、ブラウザだけで動く学習アプリです。

## 使い方

`index.html` をダブルクリックすると、ふだん使っているブラウザで開きます。
インストールもインターネット接続も不要です。

うまく開けないときは、このフォルダで次のコマンドを実行し、表示される
`http://127.0.0.1:8731/` をブラウザで開いてください。

```bash
cd ~/Downloads/topik1-vocab && python3 -m http.server 8731
```

## できること

- **出題の方向を選べる** — 韓国語→日本語 / 日本語→韓国語 / ミックス
- **問題数を選べる** — 10問 / 20問 / 全370問
- **4択で出題** — 誤答は同じ品詞の単語から選ばれるので、勘で当たりにくい
- **一度出した単語はしばらく出ない** — まだ出していない単語を先に出し、全部を一巡するまで同じ単語は二度出ません。一巡したあとは「最後に出したのが古い順」に出ます
- **答えと一緒に例文** — 回答すると、その単語を使った例文（韓国語＋日本語訳）が出ます
- **苦手な単語を通常の出題に混ぜられる** — 混ぜない / 3割 / 半分 から選べます（初期値は3割）
- **間違えた単語が「苦手」に溜まる** — ホームの「苦手な単語だけ復習」でまとめて再出題
  - 苦手な単語は、次に正解すると苦手リストから自動で外れます
- **結果画面** — その回に間違えた単語を例文つきで一覧表示。その場でもう一度復習できます
- **単語一覧** — 370語を例文つきで通して読める。韓国語・日本語どちらでも検索可能

## 学習記録について

正解数・不正解数・苦手リストは、ブラウザの localStorage に保存されます。

- 同じブラウザで開き直せば記録は残ります
- ブラウザやパソコンをまたいだ共有はされません
- ホームの「学習記録をリセット」で消せます

## 他のPC・スマホで見る

ファイルは全部が相対パスなので、どこかに置いて URL で配れば、そのまま動きます
（サーバー側の設定もビルドも不要）。

### GitHub Pages で公開する手順（インストール不要）

1. <https://github.com/new> で新しいリポジトリを作る
   - Repository name: `topik1-vocab`
   - **Public** を選ぶ（無料プランだと Pages は Public のみ）
   - 「Add a README file」はチェックしない
2. 作成直後の画面の **uploading an existing file** をクリック
3. `index.html` `style.css` `words.js` `app.js` `README.md` の5つをドラッグ＆ドロップして Commit changes
4. **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/topik1-vocab/` で開けるようになる

単語を増やしたあとは、同じリポジトリで `words.js` を上げ直せば更新されます。

### 気をつけること

- Public なので、単語データとコードは誰でも見られます（学習記録は各自のブラウザの中なので公開されません）
- **学習記録は端末ごと・ブラウザごと**です。PCとスマホで苦手リストは別々になります
- スマホでは、ブラウザの共有メニューから「ホーム画面に追加」するとアプリのように全画面で開けます

## 単語を増やすには

`words.js` の配列に、同じ形で足すだけです。アプリ側の変更は要りません。

```js
{ id: 301, ko: "지하철역", ja: "地下鉄の駅", pos: "noun", ex_ko: "지하철역이 집 바로 앞에 있어요.", ex_ja: "地下鉄の駅が家のすぐ前にあります。" },
```

- `id` は重複しない数値
- `pos` は `noun`（名詞）/ `verb`（動詞）/ `adj`（形容詞）/ `adv`（副詞）/ `conj`（接続詞）/ `pron`（疑問詞）
- `pos` は 4 択の誤答を選ぶときに使われます（同じ品詞から優先的に選ばれる）

| 品詞 | 語数 |

| 動詞 | 120 |
| 副詞 | 47 |
| 形容詞 | 45 |
| 接続詞 | 16 |
| 疑問詞 | 7 |
| **合計** | **370** |

韓国語・日本語とも訳語が重複しないように調整してあるので、
「どちらも正解に見える選択肢」は出ません。

ただし 형 / 오빠（兄）と 누나 / 언니（姉）だけは、韓国語の仕組み上どちらも同じ和訳になります。
「兄（弟から見て）」「兄（妹から見て）」のように、話し手が誰かを訳に添えて区別しています。

## 出題順のしくみ

ホームの数字（未出題／出題済み／マスター／苦手）は、この順番と対応しています。

1. まだ一度も出していない単語を優先して出す
2. 全370語を一巡したら、「最後に出したのが古い順」に出す
3. 「苦手な単語だけ復習」も同じ順番（苦手の中で出題が古いものから）

### 苦手な単語を混ぜる

「3割」を選ぶと、10問のうち3問が苦手な単語から出ます（20問なら6問、半分なら10問）。
残りの枠は上の 1→2 の順番で埋まります。

苦手な単語はこの枠で早めに戻ってくるので、ここだけは一巡を待ちません。
一巡の保証をそのまま効かせたいときは「混ぜない」を選んでください。
「全部」を選んだときは全語を出すので、混ぜる割合は関係なく苦手もすべて含まれます。
「マスター」は、直近が正解で、かつ通算2回以上正解した単語の数です。
